## Learning Objectives

By the conclusion of this project, you should be capable of [describing to anyone](/rltoken/YWniKf3iaJwqGkGNcBBZWg "describing to anyone"), **without external assistance**:

*   The Advantages of Redux
*   Managing state via redux slices
*   The Process When an Action is Dispatched in Redux
*   Understanding a Redux Store
*   Retrieving State with useSelector
*   Sending actions with useDispatch

## Prerequisites

*   All your files will be executed/compiled on Ubuntu 20.04 LTS with `node 20.x.x` and `npm 10.x.x`
*   Permitted editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
*   Every file must conclude with a new line
*   A `README.md` file is required at the root of the project directory and each task directory
*   Install Jest globally: `npm install -g jest`

# TypeScript

Basic TypeScript: types, interfaces, classes, the DOM, generics and namespaces.

Webpack bundles the tasks. Jest 24.9 checks the scripts. Tablet and mobile do not apply here.

## Requirements

- Files end with a new line
- Use the `.ts` extension when possible
- The TypeScript compiler should not show warnings or errors
- Copy the provided config files into each task folder when asked

## Tasks

0. Creating an interface for a student: render a table of first names and locations.
1. Let's build a Teacher interface: readonly names, optional experience, extra props.
